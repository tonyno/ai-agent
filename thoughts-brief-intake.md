2. We were discussing what is the level of customization that we would like to allow in the application. We didn't want to overcomplicate the solution with the goal that on one page you will be doing both radio selection and you will be also on that page having phone number entering and also product selection and so on.
The main building block for the first version was that it's everything mainly about pages. One building block is pages, and the second building block is components on the pages, and we have a relation saying on what pages can be placed what components. For example, content components or image components can be on any page, but for example, radio buttons can be only on some selected pages. We limit that flexibility of the application so that it's much seamless or easier for users to use.
