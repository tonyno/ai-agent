# Outline as our documentation platform

Internal rollout — 3-slide story for the Oaks Lab team.
Frame: our AI-first shift resets the bar for every system our work sits on — documentation included.

---

## Slide 1 — The new bar for documentation

**Title:** Docs must work for humans AND agents

**Subtitle / key message:** Going AI-first doesn't stop at how we code. It resets the bar for every system our work sits on — including documentation.

**Body (3 bullets):**
- Docs are project memory — methodology, decisions, context, rituals.
- If agents can't read, search, or update them, they can't help us think, plan, or deliver.
- New bar: documentation must be **agent-native**, not just human-readable.

**Speaker note:** The point isn't "Confluence is bad" — it's that our own standard has moved. Anything that only speaks to humans is now half a tool.

---

## Slide 2 — Outline clears the bar. Confluence doesn't.

**Title:** Why Outline, why now

**Comparison table:**

|                     | Outline                                   | Confluence                         |
|---------------------|-------------------------------------------|------------------------------------|
| **MCP support**     | ✅ Native — Claude reads/writes directly   | ❌ None                             |
| **Storage format**  | ✅ Markdown-native — LLMs parse cleanly    | ❌ Proprietary XHTML / ADF          |
| **API**             | ✅ Simple, clean                           | ❌ Heavy, inconsistent              |
| **Speed / UX**      | ✅ Fast, low friction                      | ❌ Sluggish, cluttered              |

**Proof point (footer band):**
> This workspace already runs on it. `outline-index.md` + MCP tools let agents fetch OAK'S LAB WAY docs live — no scraping, no export hacks.

**Speaker note:** We're not speculating. The integration exists, it's working, and it's already shaping how the DMT drafts and reviews.

---

## Slide 3 — What this unlocks

**Title:** Day-to-day with AI-native docs

**Body (6 concrete wins, 2 columns of 3):**

- **Methodology on tap** — agents apply OAK'S LAB WAY directly to Foundation reviews and health checks.
- **Project briefs auto-generated** from live docs (already a working skill in this repo).
- **Meeting → doc pipeline** — Granola transcripts flow into structured Outline pages via agents.
- **Natural-language search** across every project, spec, and retro.
- **Onboarding** — new hires ask agents instead of hunting through pages.
- **Docs stop rotting** — agents help maintain them, not just consume them.

**Closing line (large, centered):**
> Confluence is documentation for humans.
> Outline is documentation for the way we actually work now.

## Presenter cheat-sheet

- **Opening hook (before Slide 1):** "We've been saying 'AI-first' for months. Here's one place we haven't lived up to it yet — and how we fix it."
- **Transition Slide 1 → 2:** "So what does a doc system that clears that bar actually look like?"
- **Transition Slide 2 → 3:** "Checklists are fine. What does this change on a Tuesday?"
- **Likely objection — 'migration pain':** Yes, real. But the cost of *staying* on Confluence compounds every week we layer more agents on top of it.
- **Likely objection — 'client Confluence instances':** Unchanged. This is about our internal hub. Client tooling stays whatever the client uses.
